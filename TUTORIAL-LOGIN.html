Tutorial Login

Website E-Meli - HUT RI Ke-81

Panduan Lengkap Login untuk Pengguna Baru

Langkah 1: Buka Halaman Login

Buka browser (Chrome, Edge, Firefox) di komputer atau HP, lalu kunjungi alamat website.

Tampilan halaman login saat pertama kali dibuka

Anda akan langsung melihat halaman login tanpa perlu membuka halaman lain terlebih dahulu.

Langkah 2: Isi Username

Klik kolom Username, lalu ketik username yang sudah didaftarkan oleh administrator.

Klik kolom Username dan ketik akun Anda

Langkah 3: Isi Password

Klik kolom Password, lalu ketik sandi Anda.

Username dan password sudah terisi

Klik tombol "Tampilkan" untuk melihat password yang sedang diketekan. Ini membantu memastikan tidak ada kesalahan ketik.

Langkah 4: Klik Tombol Masuk

Setelah yakin username dan password sudah benar, klik tombol "Masuk".

Klik tombol Masuk untuk masuk ke website

Langkah 5: Login Berhasil

Jika login berhasil, Anda akan diarahkan ke halaman utama Semarak 17 Agustus.

Selamat! Anda berhasil login dan masuk ke halaman utama

Dari sini Anda bisa menjelajahi semua konten: Uraian Lomba, Hall of Fame, Database, Game, dan lainnya.

Penanganan Kesalahan

! Login Gagal: Username atau Password Salah

Pesan error muncul jika username atau password tidak cocok.

Solusi:

  • Pastikan tidak ada kesalahan ketik (perhatikan huruf besar/kecil)
  • Klik tombol "Tampilkan" untuk memeriksa password
  • Hubungi administrator jika lupa password

! Halaman Tidak Bisa Dibuka

Solusi:

  • Pastikan terhubung ke WiFi yang benar
  • Coba hapus cache browser (Ctrl+Shift+Delete)
  • Coba browser lain (Chrome, Edge, Firefox)

! Halaman Kosong Setelah Login

Solusi:

  • Tekan F5 untuk refresh halaman
  • Pastikan JavaScript aktif di browser Anda
